# Power BI Stock Market Dashboard

## Project Overview

This project was developed using **Microsoft Power BI** to analyze stock market data and present the results through an interactive dashboard.

The dashboard allows users to explore stock price behavior, trading volume, and changes in closing prices over time. It also includes an intelligent narrative visual to summarize relevant trends and insights.

## Project Objective

The objective of this project is to transform raw stock market data into an interactive and easy-to-understand dashboard.

Users can filter the report by **company** and **month** to analyze specific periods and better understand stock performance.

## Dataset

The dataset used in this project is:

`StockMarket.xlsx`

The dataset contains historical stock market information with the following fields:

| Column    | Description                           |
| --------- | ------------------------------------- |
| `Empresa` | Company name                          |
| `Data`    | Date of the stock market record       |
| `Open`    | Opening stock price                   |
| `High`    | Highest stock price during the period |
| `Low`     | Lowest stock price during the period  |
| `Close`   | Closing stock price                   |
| `Volume`  | Number of shares traded               |

The dataset contains approximately **1,260 stock market records**.

## Dashboard Features

The Power BI dashboard includes several interactive visualizations and analysis tools.

### Total Volume Over Time

Displays the total trading volume over time, making it possible to identify periods of higher or lower market activity.

### Average Stock Values Over Time

Shows the average values for:

* Open
* High
* Low
* Close
* Volume

The data can be analyzed by year and month.

### Month-over-Month Close Variation

Displays the percentage change in the average closing price from one month to another.

This calculation helps identify increases or decreases in stock performance over time.

### Company Filter

Allows users to select a specific company and analyze only its stock market information.

### Month Filter

Allows users to filter the dashboard by month and focus on specific periods.

### Intelligent Narrative

The dashboard includes Power BI's **Intelligent Narrative** feature, which automatically generates text-based insights based on the information displayed in the report.
